# Release Readiness

Prepare, do not assume, ship-time human gates:
- release approval;
- final UX judgement;
- security/risk acceptance;
- regulatory/compliance interpretation.

Assemble release notes, traceability report, CI results, scan results, open risks, accepted caveats, rollback plan, and production feedback hooks. Do not deploy production without explicit human approval.
